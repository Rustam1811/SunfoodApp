# Система Акций - Документация

## Обзор

Реализована полноценная система акций для SunfoodApp с возможностью создания гибких промо-акций через админ-панель.

## Архитектура

### 1. Типы данных (`admin/types/promo.ts`)

**Promo** - основная структура акции:
- `conditions` - массив условий (время, день недели, товар, сумма корзины)
- `rewards` - массив наград (скидка %, фиксированная скидка, бесплатный товар, купи X получи Y, бонусы)
- `isActive` - статус активности
- `priority` - приоритет применения
- `stackable` - можно ли комбинировать с другими акциями

### 2. Firestore сервис (`admin/services/promoService.ts`)

Функции для работы с базой данных:
- `createPromo()` - создание акции
- `updatePromo()` - обновление акции
- `deletePromo()` - удаление акции
- `getAllPromos()` - получить все акции
- `getActivePromos()` - получить только активные акции
- `incrementPromoUsage()` - увеличить счетчик использования

### 3. Движок применения акций (`src/services/promoEngine.ts`)

**checkPromoConditions()** - проверяет, соответствует ли корзина всем условиям акции:
- `time_range` - временной диапазон (например, 08:00-12:00)
- `product_quantity` - минимальное количество конкретного товара
- `min_cart_value` - минимальная сумма корзины
- `specific_product` - наличие конкретного товара
- `day_of_week` - день недели (0-6)
- `category` - наличие товара из категории

**applyPromo()** - применяет награды:
- `percentage_discount` - процентная скидка (на корзину/товар/категорию)
- `fixed_discount` - фиксированная скидка
- `free_product` - бесплатный товар
- `buy_x_get_y` - купи X получи Y бесплатно
- `bonus_points` - дополнительные бонусные баллы

**applyAllPromos()** - применяет все подходящие акции с учетом приоритета и stackable

### 4. Контекст акций (`src/contexts/PromoContext.tsx`)

Предоставляет глобальный доступ к:
- `activePromos` - список активных акций
- `appliedPromos` - применённые к корзине акции
- `totalDiscount` - общая скидка
- `freeProducts` - список бесплатных товаров
- `bonusPoints` - дополнительные бонусы
- `calculatePromosForCart()` - пересчитать акции для корзины

### 5. Админ-панель (`admin/pages/PromoManager.tsx`)

Полнофункциональное управление акциями:
- Список всех акций с фильтрами (все/активные/неактивные)
- Создание новой акции через многошаговую форму:
  - Шаг 1: Основная информация
  - Шаг 2: Условия (можно добавить несколько)
  - Шаг 3: Награды (можно добавить несколько)
- Редактирование существующих акций
- Удаление акций
- Отображение статистики использования

### 6. Интеграция в корзину (`src/pages/Order.tsx`)

При изменении корзины:
1. Автоматически вычисляются применимые акции
2. Отображаются активные акции с описанием
3. Показывается общая скидка
4. Отображаются бесплатные товары
5. Пересчитывается итоговая сумма

### 7. Отображение на главной (`src/components/PromoSection.tsx`)

Красивое отображение активных акций на главной странице с:
- Бейджами
- Условиями (время, день, сумма)
- Наградами (скидки, бонусы)
- Изображениями

## Примеры использования

### Пример 1: Утренняя акция "Средний латте + бесплатный"

**Условия:**
- Время: 08:00 - 12:00
- Товар: Латте средний (ID: 301), минимум 1 шт

**Награды:**
- Купи 1 получи 1 бесплатно (тот же товар)

```typescript
{
  title: "Утренний кофе 1+1",
  description: "Купи средний латте до 12:00 и получи второй бесплатно!",
  conditions: [
    {
      type: 'time_range',
      timeRange: { start: '08:00', end: '12:00' }
    },
    {
      type: 'product_quantity',
      productId: 301,
      minQuantity: 1
    }
  ],
  rewards: [
    {
      type: 'buy_x_get_y',
      buyXGetY: {
        buyQuantity: 1,
        getQuantity: 1,
        productId: 301
      }
    }
  ],
  priority: 10,
  stackable: false
}
```

### Пример 2: Скидка 15% по выходным

**Условия:**
- День недели: суббота (6), воскресенье (0)
- Минимальная сумма: 2000₸

**Награды:**
- Скидка 15% на всю корзину

```typescript
{
  title: "Выходные со скидкой",
  description: "Скидка 15% на заказ от 2000₸ в выходные",
  conditions: [
    {
      type: 'day_of_week',
      daysOfWeek: [0, 6]
    },
    {
      type: 'min_cart_value',
      minValue: 2000
    }
  ],
  rewards: [
    {
      type: 'percentage_discount',
      value: 15,
      applyTo: 'cart'
    }
  ],
  priority: 5,
  stackable: true
}
```

## Как владельцу добавить акцию

1. Войти в админ-панель
2. Перейти в раздел "Акции и промо"
3. Нажать "Создать акцию"
4. Заполнить основную информацию:
   - Название
   - Описание
   - Даты действия
   - Приоритет
5. Добавить условия (можно несколько):
   - Выбрать тип условия
   - Настроить параметры
6. Добавить награды (можно несколько):
   - Выбрать тип награды
   - Указать значения
7. Сохранить акцию

Акция автоматически применится ко всем подходящим заказам!

## Технические детали

- **База данных**: Firestore collection `promos`
- **Валидация**: проверка всех условий перед применением
- **Производительность**: кэширование активных акций
- **UI/UX**: анимированные карточки, цветовая индикация
- **Гибкость**: любые комбинации условий и наград
