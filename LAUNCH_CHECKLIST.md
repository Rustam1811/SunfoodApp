## Перед запуском

### 1. Firestore настройка
- [ ] Создана коллекция `promos` в Firestore
- [ ] Настроены индексы для коллекции:
  ```
  - isActive (ASC), startDate (ASC), endDate (ASC)
  - priority (DESC)
  ```
- [ ] Настроены правила безопасности:
  ```javascript
  // Firestore Rules
  match /promos/{promoId} {
    allow read: if true; // Все могут читать активные акции
    allow write: if request.auth != null && 
                   get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['owner', 'admin'];
  }
  ```

## Первая акция (Рекомендуется)

### 13. Тестовая акция "Приветственная"
Создайте простую акцию для проверки системы:

```typescript
{
  title: "🎉 Запуск системы акций!",
  description: "Скидка 10% на первый заказ",
  conditions: [
    { type: 'min_cart_value', minValue: 500 }
  ],
  rewards: [
    { type: 'percentage_discount', value: 10, applyTo: 'cart' }
  ],
  isActive: true,
  priority: 50,
  stackable: true,
  showOnHome: true
}
```
