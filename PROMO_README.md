# 🎉 Система Акций для SunfoodApp

## Что реализовано

Создана полнофункциональная система управления акциями для приложения SunfoodApp. Теперь владелец может создавать любые промо-акции через админ-панель, и они автоматически применяются к заказам клиентов.

## 🚀 Основные возможности

### Для владельца (Админ-панель)

1. **Создание гибких акций** с любыми условиями:
   - ⏰ Временной диапазон (например, с 8:00 до 12:00)
   - 📅 Дни недели (например, только по выходным)
   - 🛒 Минимальная сумма корзины
   - 📦 Конкретный товар или количество
   - 🏷️ Категория товаров

2. **Разнообразные награды**:
   - 💰 Процентная скидка (например, -15%)
   - 💵 Фиксированная скидка (например, -500₸)
   - 🎁 Купи X получи Y бесплатно
   - 🆓 Бесплатный товар
   - ⭐ Дополнительные бонусные баллы

3. **Управление**:
   - ✅ Активация/деактивация акций
   - 🎯 Приоритеты применения
   - 📊 Статистика использования
   - 🔄 Редактирование и удаление
   - 🏠 Отображение на главной странице

### Для клиентов

1. **Автоматическое применение** - акции применяются автоматически при оформлении заказа
2. **Прозрачность** - клиент видит какие акции активны и сколько экономит
3. **Видимость** - активные акции отображаются на главной странице
4. **Комбинирование** - возможность применять несколько акций одновременно (если разрешено)

## 💡 Примеры использования

### Пример 1: "Утренний кофе 1+1"
**Условие:** Купить средний латте с 8:00 до 12:00  
**Награда:** Второй такой же латте бесплатно

```typescript
{
  title: "Утренний кофе 1+1",
  description: "Купи средний латте до 12:00 и получи второй бесплатно!",
  conditions: [
    { type: 'time_range', timeRange: { start: '08:00', end: '12:00' } },
    { type: 'product_quantity', productId: 301, minQuantity: 1 }
  ],
  rewards: [
    { type: 'buy_x_get_y', buyXGetY: { buyQuantity: 1, getQuantity: 1, productId: 301 } }
  ]
}
```

### Пример 2: "Счастливые выходные"
**Условие:** Заказ от 2000₸ в субботу или воскресенье  
**Награда:** Скидка 15% + 50 бонусных баллов

```typescript
{
  title: "Счастливые выходные",
  description: "Скидка 15% на заказ от 2000₸ в выходные",
  conditions: [
    { type: 'day_of_week', daysOfWeek: [0, 6] },
    { type: 'min_cart_value', minValue: 2000 }
  ],
  rewards: [
    { type: 'percentage_discount', value: 15, applyTo: 'cart' },
    { type: 'bonus_points', value: 50 }
  ]
}
```

## 🎯 Как владельцу создать акцию

### Через Админ-панель:

1. **Войти** в админ-панель `/admin`
2. **Перейти** в раздел "Акции и промо"
3. **Нажать** кнопку "Создать акцию"
4. **Заполнить** основную информацию:
   - Название (например: "Утренний кофе")
   - Описание (например: "Купи средний латте до 12:00 и получи второй бесплатно!")
   - Даты начала и окончания
   - Приоритет (чем выше, тем раньше применится)
   
5. **Добавить условия** (можно несколько):
   - Нажать на кнопку нужного типа условия
   - Заполнить параметры
   
6. **Добавить награды** (можно несколько):
   - Нажать на кнопку нужного типа награды
   - Указать значения
   
7. **Настроить дополнительно**:
   - ✅ Активна
   - 🔗 Можно комбинировать с другими акциями
   - 🏠 Показывать на главной странице
   
8. **Сохранить** акцию

Готово! Акция сразу же начнет применяться к подходящим заказам.

## 🛠️ Технические детали

### База данных
- **Коллекция:** `promos`
- **Индексы:** по `isActive`, `startDate`, `endDate`, `priority`

### Производительность
- Кэширование активных акций в PromoContext
- Вычисление только при изменении корзины
- Оптимизированные запросы к Firestore

### Безопасность
- Валидация всех условий перед применением
- Проверка дат и приоритетов
- Защита от дублирования скидок

## 📊 Что видит клиент

### На главной странице
- Красивые карточки с активными акциями
- Условия (время, дни, сумма)
- Награды (скидки, бонусы, подарки)

### В корзине
- Список применённых акций
- Описание каждой акции
- Сумма скидки
- Бесплатные товары
- Дополнительные бонусные баллы
- Итоговая сумма с учётом всех акций
